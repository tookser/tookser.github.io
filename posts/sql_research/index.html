Материалы по изучению SQL

2026-07-09 :: Иван :: 1 min read (143 words)
#полезное  #sql  #интересности 

  • Интерактивный тренажёр по SQL от Озеровой Галины на Степике. Хорошая подача, интерактивно (и мало теории), значительную часть курса на повторение.

  • https://www.practicewindowfunctions.com - на английском, вполне нормально, но чувствуется рука нейросети🤖🤖🤖. Например, там есть туториал по оконным функциям.

  • Также LLM оказывается полезной, например, может указать на пробелы в знаниях. Лучше описывать свою ситуацию подробнее (что уже знаешь, что хочешь знать, сколько времени можешь выделить), и указывать в промте, что нужно спросить обратную связь (стандартные рекомендации для таких целей).

  • Советовали также книгу «Освой SQL самостоятельно за 10 минут» Бена Форты, у неё есть русскоязычное издание 2021 года. Пока не смотрел, но выглядит адекватно (кроме названия :).

  • Из прямо интересного-игрового знаю https://mystery.knightlab.com - детектив, где нужно найти убийцу с помощью запросов к базе данных. Это не родоначальник жанра игр по SQL - первая, которую нахожу, это https://sql-island.informatik.uni-kl.de (через меню вверху слева можно поменять язык на английский).
